# Nuri Docs

[Nuri](https://github.com/Nuri-Capstone) 프로젝트를 개인적으로 포크하여 개발/학습하며 정리하는 문서 레포입니다. <br>
프론트엔드와 백엔드에 걸친 아키텍처, API 명세, 개발 노트 등 두 레포에 공통적인 문서를 이곳에서 관리합니다.

## Project Overview

> AI 기반 한국어 대화 학습 앱

- 사용자는 앱에서 음성으로 대화하고, AI의 응답과 피드백을 받습니다.
- 대화 내용은 채팅 형태로 기록/조회되며, 홈/설정 등 부가 기능을 제공합니다.

## Tech Stack

**Backend**
- Spring Boot 3.3, Java 17
- Spring Data JPA (PostgreSQL), Spring Data MongoDB
- Spring Batch, Spring WebSocket, Spring Security + JWT
- AWS SDK (Transcribe, Polly, S3)

**Frontend**
- React Native 0.75, React 18
- React Navigation (bottom-tabs / native-stack / stack)
- styled-components
- react-native-audio-recorder-player, react-native-sound-player (음성 녹음/재생)
